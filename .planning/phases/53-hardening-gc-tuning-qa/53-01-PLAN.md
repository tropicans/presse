# Plan 53-01: Hardening, EXIF Stripping, Payload Limiting & Full QA

## Goal
Harden the entire file upload stack against OOM and privacy leaks by enforcing strict body size bounds, stripping EXIF/GPS metadata from uploaded images before spooling, and executing a comprehensive end-to-end verification across all test suites, types, builds, and containers.

## Tasks
1. **EXIF / Metadata Stripper (`src/lib/image-exif.ts`)**:
   - Implement `stripJpegExif` (skips APP1 0xFFE1 and COM 0xFFFE).
   - Implement `stripPngMetadata` (skips eXIf, tEXt, zTXt, iTXt chunks).
   - Implement `stripImageMetadata(buffer, mime)`.
   - Write comprehensive unit tests in `src/lib/image-exif.test.ts`.
2. **Apply Stripping & Payload Bounds**:
   - Update `src/app/api/public/files/upload/route.ts` with Content-Length check (>12MB -> 413) and EXIF stripping before spooling.
   - Update `src/app/api/admin/files/upload/route.ts` with Content-Length check (>12MB -> 413) and EXIF stripping before spooling.
   - Update `infra/nginx/benchmark.conf` with `client_max_body_size 12M;`.
3. **Comprehensive Verification & Container Rebuild**:
   - Run `npm test` across all 28+ test suites.
   - Run `npm run lint`.
   - Run `npx tsc --noEmit --pretty false`.
   - Build containers via `docker compose build app worker`.
   - Start containers and verify `/api/health` returns `status: ok`.
