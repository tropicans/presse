# Plan 52-01: Admin Surfaces, Attachment Upload & Export Integration

## Goal
Enable administrators to manage, inspect, and download submission file attachments, upload supplementary attachments, safely export files to Excel with hyperlinked app URLs and formula escaping, and ensure complete cascading cleanup on submission deletion.

## Tasks
1. **Core Domain & Cleanup in `src/lib/forms.ts`**:
   - Update `listAdminFormSubmissions` to load `submission_files` for the page's submissions, populating `item.files`.
   - Update `deleteAdminFormSubmission` to query and delete MinIO objects via `deleteObject(key)`, and delete `file_upload_jobs` and `submission_files` records.
   - Implement `escapeExcelFormula(value)` in `src/lib/forms.ts`.
   - Update `exportAdminFormSubmissionsWorkbook` to format file columns as `Filename (URL: /api/files/[id])` with formula escaping.
2. **Admin Upload Endpoint (`POST /api/admin/files/upload`)**:
   - Create `src/app/api/admin/files/upload/route.ts`:
     - Admin session check (`getAdminSession()`).
     - Multipart parse (`file`, `submissionId`).
     - Magic-byte validation (`validateUploadedFileBuffer`).
     - Spooling in `file_upload_jobs` and inserting into `submission_files` with `submission_id = submissionId, field_id = NULL, status = 'QUEUED'`.
     - Returns `{ success: true, file: AdminSubmissionFileItem }`.
3. **Admin UI in `src/components/AdminFormSubmissions.tsx`**:
   - Display file answers in table/grid as clickable link to `/api/files/[id]`.
   - Add **Lampiran (Attachments)** panel per submission:
     - File name, formatted size, origin badge (`Peserta` / `Admin`), sync status badge (`Tersinkron` / `Menunggu sinkronisasi`).
     - Download link pointing to `/api/files/[id]`.
     - File upload button allowing admin to add supplementary attachments.
4. **Automated Testing & Verification**:
   - Unit tests for admin upload API (`src/app/api/admin/files/upload/admin-upload.test.ts`).
   - Unit tests for Excel formula escaping and file cell export.
   - Unit tests for submission deletion with file purging.
   - Pre-flight checks (`npm test`, `npm run lint`, `npx tsc`).
   - Container rebuild & health check.
