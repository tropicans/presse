# Quick Task: Ganti dari Himpun menjadi Form

## Goal

Hapus semua sisa identitas `Himpun` di kode sumber runtime dan ganti ke `Form`.
Brand text sudah `Form`; sisa yang harus dibereskan adalah nama komponen (`HimpunLogo`), class CSS legacy (`himpun-logo-*`), dan nama database default di config test (`himpun`).

Out of scope: file `.planning/**` historis (arsip quick task lama) dan `AGENTS.md` baris "formerly HIMPUN" (catatan historis yang memang sengaja).

## Tasks

### Task 1: Rename komponen logo + class CSS

**files:**
- `src/components/FormLogo.tsx` (sumber kebenaran, sudah ada & sudah benar)
- `src/components/HimpunLogo.tsx` (hapus)
- 12 konsumen import `HimpunLogo` (lihat daftar di frontmatter)

**action:**
1. Ganti setiap `import HimpunLogo from '@/components/HimpunLogo'` (dan varian relatif `'./HimpunLogo'`) menjadi `import FormLogo from '@/components/FormLogo'`.
2. Ganti setiap pemakaian JSX `<HimpunLogo ... />` menjadi `<FormLogo ... />`.
3. Hapus `src/components/HimpunLogo.tsx` setelah semua import berpindah.
4. `src/components/FormLogo.tsx` sudah versi bersih (tanpa `himpun-*` class) — jangan regresi ke versi lama.

**verify:**
```bash
rg -n "Himpun|himpun" src
```
harus 0 hasil.

**done:** Tidak ada lagi file/identifier `HimpunLogo`; build/lint/tsc lulus.

### Task 2: Bersihkan nama `himpun` di konfigurasi test

**files:**
- `vitest.config.ts`

**action:** Ubah `DATABASE_URL: 'postgresql://postgres:postgres@localhost:5432/himpun'` menjadi `...localhost:5432/form'`.

**verify:** `rg -n "himpun" vitest.config.ts` → 0 hasil.

**done:** Config test tidak menyebut `himpun` lagi.
