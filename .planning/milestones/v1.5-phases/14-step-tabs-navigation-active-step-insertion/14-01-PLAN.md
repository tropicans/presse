# Plan 14-01: Step Tabs Navigation & Active-Step Insertion

## Goal
Implement a step-based tab navigation bar in the admin form builder that allows filtering the field cards view by individual step or viewing all steps (BUILDER-01), displaying reactive field count badges and empty-step visual warnings on each tab (BUILDER-02), and automatically inserting new fields created via toolbar buttons directly into the currently active step (BUILDER-09).

  </action>
