# Roadmap - Milestone v1.7: Monochrome Design System Overhaul

Milestone goal: Merombak total sistem desain visual aplikasi isian dari palet teal/deep blue ke gaya **Monochrome Minimalist & High-Contrast (Swiss / Tech Luxury Style)** yang bersih, presisi, dan konsisten pada seluruh antarmuka publik dan dashboard admin di kedua mode (Light & Dark).

---

## Phase 20: Monochrome Design Tokens & Global Visual Foundation

Goal: Menetapkan skala warna monokromatis terstandarisasi, mendokumentasikan spesifikasi desain, dan menyelaraskan token global CSS serta tema Light & Dark.
Requirements: MONO-01, MONO-02, MONO-03

### Success Criteria

1. Seluruh token CSS dasar di `src/app/globals.css` diperbarui ke palet monokrom (Obsidian `#000000`/`#09090b`, Zinc `#27272a`..`#f4f4f5`, Stark White `#ffffff`).
2. Spesifikasi lengkap "The Monochrome Ledger" didokumentasikan di `new_design/dashboard/DESIGN.md`.
3. Mode terang dan gelap harmonis dengan hairline border 1px dan ambient shadow yang konsisten.
4. Unit test token CSS `src/app/globals.test.ts` memvalidasi keberadaan dan nilai token monokrom.

---

## Phase 21: Public Form & Confirmation Experience Monochrome Transformation

Goal: Mengubah estetika seluruh pengalaman publik (kartu form, stepper multi-langkah, tombol navigasi, signature pad, skala Likert, dan layar konfirmasi) ke gaya monokromatis berdaya guna tinggi.
Requirements: MONO-04, MONO-05, MONO-06

### Success Criteria

1. Formulir publik di `/f/[slug]` dan komponen `AttendanceForm.tsx` tampil dengan layout monokrom bersih, kontras tinggi, dan nyaman dibaca.
2. Stepper progres langkah dan tombol aksi ("Langkah Selanjutnya" / "Kirim Formulir") menggunakan kontras monokrom tajam tanpa gradien teal lama.
3. Digital signature pad dan kisi Likert terintegrasi sempurna dengan tema monokrom.
4. Halaman `/success` menyajikan konfirmasi submission yang tenang dan terarah dengan badge monokromik presisi.

---

## Phase 22: Admin Dashboard & Form Builder Monochrome Overhaul

Goal: Merombak total antarmuka dashboard admin, manajemen form, form builder kompleks, tabel data kiriman, dan dialog modal dalam gaya monokromatis.
Requirements: MONO-07, MONO-08

### Success Criteria

1. Halaman admin `/admin/login`, `/admin/forms`, dan builder `/admin/forms/[id]/edit` selaras dengan gaya monokrom.
2. Tab navigasi langkah, kartu field accordion yang dapat diciutkan, peta form outline, dan floating toolbar tampil konsisten dan responsif.
3. Tabel data kiriman (`/admin/forms/[id]/submissions`), sticky headers, filter badges, dan modal ringkasan AI mengadopsi palet monokrom tanpa sisa teal lama.

---

## Phase 23: Quality Assurance, Visual Regression & Build Verification

Goal: Melakukan verifikasi komprehensif terhadap unit tests, linting, type safety, standalone production build, dan pengujian runtime container Docker.
Requirements: MONO-09

### Success Criteria

1. Seluruh suite pengujian otomatis (`npm run test`) lulus 100% (56/56 tests).
2. ESLint (`npm run lint`) dan TypeScript strict check (`npx tsc --noEmit`) bersih tanpa error.
3. Standalone Next.js production build (`npm run build`) berhasil mengompilasi 13 routes.
4. Docker Compose stack berjalan sehat (`isian-postgres`, `isian-app`, `isian-worker`) dan merespons endpoint health `/api/health`.
