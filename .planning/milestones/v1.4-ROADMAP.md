# Roadmap - Milestone v1.4: UI Polish & Admin Experience Enhancement

Milestone goal: Mengimplementasikan peningkatan visual dan ergonomi antarmuka pengguna pada suite Admin (`/admin/forms` dan `/admin/forms/[id]/submissions`) berdasarkan temuan UI Designer Audit untuk meningkatkan kenyamanan, persepsi performa, dan estetika premium.

---

## Phase 12: Sticky Table Headers & Skeleton Shimmer Loaders

Goal: Implementasi sticky table header dan skeleton shimmer loading state pada dashboard dan tabel submissions admin.
Requirements: TABLE-01, LOAD-01, LOAD-02

### Success Criteria

1. Baris header kolom (`thead th`) pada tabel submissions (`/admin/forms/[id]/submissions`) tetap terlihat di posisi atas saat scroll vertikal panjang dengan latar belakang solid adaptif (light/dark mode).
2. Tampilan loading statis/spinner pada halaman dashboard formulir (`/admin/forms`) digantikan oleh animasi skeleton shimmer rows yang mencerminkan struktur kolom tabel data.
3. Tampilan loading awal pada halaman kiriman formulir (`/admin/forms/[id]/submissions`) digantikan oleh skeleton shimmer stat cards dan submissions cards placeholder.

---

## Phase 13: Enhanced Empty States & Visual CTAs

Goal: Mengganti empty state teks polos dengan ilustrasi SVG minimalis, copy informatif, dan tombol Call-to-Action (CTA) kontekstual.
Requirements: EMPTY-01, EMPTY-02

### Success Criteria

1. Dashboard formulir (`/admin/forms`) menyajikan ilustrasi SVG minimalis dan tombol utama "Buat Formulir Baru" saat belum ada formulir yang dibuat.
2. Halaman kiriman (`/admin/forms/[id]/submissions`) menyajikan ilustrasi SVG minimalis dan aksi kontekstual berdasarkan status form (Copy URL publik untuk PUBLISHED, buka form editor untuk DRAFT/ARCHIVED).
3. State kosong saat pencarian/filter menghasilkan 0 data menyajikan pesan yang jelas dan tombol reset filter satu klik.
