# Roadmap - Milestone v1.8: Editorial Minimalist Monochrome Transformation

Milestone goal: Mentransformasikan seluruh visual aplikasi `isian` ke gaya **Minimalist Monochrome (Editorial Luxury & Architectural Precision)**: tipografi serif klasik (`Playfair Display`, `Source Serif 4`, `JetBrains Mono`), palet murni `#000000` dan `#FFFFFF`, radius 0px di seluruh elemen, zero drop shadows, garis arsitektural terukur (1px hingga 8px), tekstur kertas & garis halus, serta interaksi biner instan.

---

## Phase 24: Editorial Serif Typography & Global Zero-Radius Tokens Foundation

Goal: Menetapkan fondasi visual tipografi serif klasik Google Fonts, skala token monokrom murni, peniadaan global border radius (0px), penghapusan drop shadows, dan penambahan tekstur kertas arsitektural.
Requirements: EDIT-01, EDIT-02, EDIT-03, EDIT-04, EDIT-05

### Success Criteria

1. Font Google Fonts `Playfair Display`, `Source Serif 4`, dan `JetBrains Mono` dimuat via `@import` di `src/app/globals.css`.
2. Variabel CSS `--primary-900: #000000`, `--ledger-bg: #ffffff`, dan palet hitam/putih murni aktif.
3. Aturan `*, *::before, *::after { border-radius: 0px !important; }` ditegakkan secara global.
4. Semua `--shadow-*` diset ke `none` dan hierarki garis arsitektural (1px, 2px, 4px, 8px) didefinisikan.
5. Background body memiliki tekstur paper grid berulang 32px.
6. Spesifikasi desain di `new_design/dashboard/DESIGN.md` diperbarui untuk v1.8.

---

## Phase 25: Public Form & Confirmation Experience Editorial Overhaul

Goal: Mengubah tampilan seluruh pengalaman pengisian formulir publik (`/f/[slug]`, `AttendanceForm.tsx`, dan `/success`) ke estetika editorial minimalis mewah.
Requirements: EDIT-06, EDIT-07

### Success Criteria

1. Komponen form publik menampilkan judul serif Playfair Display berukuran besar dengan garis pembatas tegas 2px.
2. Badge langkah progres menampilkan format monospace terisi nol (`Langkah 01 / 04`).
3. Seluruh kontrol input, textarea, select bergaris tepi 2px solid siku tanpa sudut membulat.
4. Pilihan radio dan checkbox mengadopsi kotak siku dengan inversi warna biner instan (<100ms) saat aktif.
5. Canvas tanda tangan dibingkai garis hitam solid siku 2px.
6. Halaman `/success` menampilkan kartu konfirmasi dengan garis bawah judul tebal 4px, badge ID monospace, dan tombol aksi berinversi instan.

---

## Phase 26: Admin Suite & Form Builder Editorial Minimalist Transformation

Goal: Menyelaraskan seluruh antarmuka admin (`/admin/forms`, editor builder form, tab langkah, dan dasbor data kiriman) dengan standar monokrom editorial arsitektural.
Requirements: EDIT-08

### Success Criteria

1. Header dasbor admin, judul halaman, dan kartu builder menggunakan tipografi Playfair Display dan JetBrains Mono.
2. Header tabel dasbor form dan submissions menggunakan kontras tegas dengan border pemisah hairline 1px dan zero shadows.
3. Panel form builder, input builder, dan kartu konfigurasi field bergaris tepi 2px solid tanpa sudut melengkung.
4. Tab langkah navigasi builder berbentuk persegi bersiku 90 derajat dengan inversi biner saat aktif.
5. Dasbor data kiriman menampilkan kartu respons, chip tipe peserta, dan kisi jawaban terstruktur rapi dengan gaya monokrom editorial.

---

## Phase 27: Multi-Tier Verification, Visual Regression & Docker Container Up

Goal: Melakukan verifikasi multi-tier (Vitest test suite, ESLint, TypeScript compiler, Next.js production build), membangun container Docker runtime, menjalankan container, dan memastikan status health operasional.
Requirements: EDIT-09

### Success Criteria

1. Suite unit/integration testing Vitest lulus 100% (61/61 tests passing).
2. Linter ESLint bersih tanpa error maupun peringatan.
3. Pengecekan tipe TypeScript strict (`npx tsc --noEmit`) berhasil tanpa error.
4. Build produksi Next.js 16 standalone (`npm run build`) berhasil mengompilasi seluruh 22 routes.
5. Image Docker `isian-runtime:local` berhasil dibangun dan di-deploy via `docker compose --env-file .env.production up -d`.
6. Seluruh container (`isian-postgres`, `isian-app`, `isian-worker`) berstatus healthy dan merespons endpoint `/api/health`.
