## Cross-Phase E2E Flow Audits
1. **Public Submission Flow with File Upload:** Verified end-to-end. Participant drags file, client validates format & bounds, `POST /api/public/files/upload` sniffs magic bytes and strips EXIF, spools to PostgreSQL `file_upload_jobs` and `submission_files`, returns `{fileId}`. On submit, form links `fileId` to `submission_id` and promotes status to `QUEUED`.
2. **Asynchronous MinIO Synchronization:** Verified end-to-end. `scripts/submission-worker.mjs` triggers `POST /api/internal/file-jobs/process` with worker token, acquires jobs with `FOR UPDATE SKIP LOCKED`, uploads to MinIO with deterministic object keys (`files/${fileId}`), updates record to `SYNCED`, and nulls out `bytea` payload in database.
3. **Private Admin File Retrieval:** Verified end-to-end. `GET /api/files/[id]` validates admin session, validates UUID/ID format, blocks traversal, checks storage status, and transparently streams from Postgres spool (if pending) or MinIO object (if synced) with RFC 5987 `Content-Disposition` and `nosniff`.
4. **Admin Supplementary Uploads & Submissions Drawer:** Verified end-to-end. Admin views submission details, opens attachments drawer showing sync badge and origin, and can upload supplementary files via `POST /api/admin/files/upload` without mutating user-submitted answers.
5. **Data Deletion & Orphan Garbage Collection:** Verified end-to-end. Deleting a submission purges MinIO objects via `deleteObject`, deletes `file_upload_jobs`, and removes `submission_files`. Abandoned public uploads are swept and purged after 24 hours.
6. **Hardened Excel Export:** Verified end-to-end. Generates `.xlsx` where file cells contain filenames hyperlinked to internal application URLs (`/api/files/[id]`), with formula injection prefixes (`=`, `+`, `-`, `@`) defused.
