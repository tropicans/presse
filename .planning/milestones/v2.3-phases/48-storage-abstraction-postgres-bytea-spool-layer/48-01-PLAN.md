## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-48-01 | Tampering | `src/lib/file-storage.ts` SQL queries | critical | mitigate | All SQL queries in `file-storage.ts` strictly use tagged template literals (`prisma.$executeRaw` / `prisma.$queryRaw`) with parameter bindings. No string concatenation for user-controlled filenames or IDs (per D-01). |
| T-48-02 | Tampering | `src/lib/file-storage.ts` state machine | high | mitigate | Enforce `assertValidFileStatusTransition` check before state changes and include guard clauses in SQL (`WHERE status = 'PENDING_UPLOAD'`) to prevent illegal state rewinds or resurrection (per D-03). |
| T-48-03 | Denial of Service | `src/lib/file-storage.ts` bytea handling | medium | mitigate | Spooled payload retrieval returns Node Buffer converted directly from bytea offset without multi-copy duplication; payload is stored once in `file_upload_jobs` and referenced by file_id (per D-04, FILE-03). |
| T-48-04 | Information Disclosure | `src/lib/file-storage.ts` timestamps | low | mitigate | Store and evaluate all timestamps with explicit `NOW() AT TIME ZONE 'UTC'` to eliminate timezone calculation drifts (per D-05). |
| T-48-SC | Tampering | npm packages | high | mitigate | Package-legitimacy gate: no new external packages added; all operations use existing PrismaPg adapter and native Node Buffer. |
</threat_model>
