# Plan 51-01: Private File Serving Route

## Goal
Implement secure private file serving endpoint `GET /api/files/[id]` that allows authenticated admins to stream files whether spooled in PostgreSQL or synced in MinIO, while enforcing strict security headers against XSS and MIME confusion.

## Tasks
1. Create `src/app/api/files/[id]/route.ts`:
   - Admin authentication check (`getAdminSession()`) returning 401 if missing.
   - ID sanitization & traversal prevention returning 400 if invalid.
   - File retrieval via `getFileForServing(id)` returning 404 if not found.
   - Dual-source byte retrieval (spool `file.payload` or MinIO `getObjectBytes(objectKey)`).
   - Strict response headers (`Content-Disposition: attachment`, `nosniff`, `Cache-Control`).
2. Write unit tests in `src/app/api/files/[id]/file-serving.test.ts`:
   - Unauthenticated access returns 401.
   - Invalid ID / traversal attempt returns 400.
   - Nonexistent file returns 404.
   - Spooled file returns 200 with spool bytes and correct headers.
   - Synced MinIO file returns 200 with MinIO bytes and correct headers.
   - Verified attachment header, nosniff, and content type.
3. Validate and verify:
   - Run tests (`npm test`).
   - Run linter and typecheck.
   - Build and verify container health.
