# Requirements: Milestone v1.7 Monochrome Design System Overhaul

**Milestone:** v1.7  
**Status:** Shipped (2026-09-27)  
**Goal:** Merombak total sistem desain visual aplikasi isian dari palet teal/deep blue ke gaya **Monochrome Minimalist & High-Contrast (Swiss / Tech Luxury Style)** yang bersih, presisi, dan konsisten pada seluruh antarmuka publik dan dashboard admin di kedua mode (Light & Dark).

## Requirements

### Global Tokens & Visual Foundation

- [x] **MONO-01**: **Monochrome Design Tokens & Palette Refactor** — Mengganti seluruh token warna teal/blue di `src/app/globals.css` dengan skala warna monokromatik terstandarisasi (Obsidian `#000000`/`#09090b`, Deep Charcoal `#121214`/`#18181b`, Grayscale/Zinc `#27272a` hingga `#f4f4f5`, Stark White `#ffffff`) serta memperbarui spesifikasi di `new_design/dashboard/DESIGN.md`.
- [x] **MONO-02**: **Light & Dark Theme Harmonization** — Menyelaraskan kanvas latar, efek radial sheen halus, kontras teks utama (`--text-primary`), teks sekunder (`--text-muted`), dan tombol `ThemeToggle` dalam mode terang maupun gelap tanpa artefak warna lama.
- [x] **MONO-03**: **Precision Hairline Borders & Restrained Elevation** — Menghilangkan border tebal/berwarna dan menggantinya dengan hairline border presisi 1px (`rgba(0,0,0,0.08)` pada mode terang dan `rgba(255,255,255,0.08)` pada mode gelap) serta elevasi bayangan halus (*ambient shadows*).

### Public Form & Confirmation Experience

- [x] **MONO-04**: **Monochrome Public Form Interface** — Menata ulang tampilan formulir publik (`/f/[slug]` & `AttendanceForm.tsx`): kartu form, progress stepper multi-langkah, tombol navigasi ("Langkah Selanjutnya" / "Kirim Formulir"), field input, radio pill, dan checkbox dengan gaya monokrom kontras tinggi.
- [x] **MONO-05**: **High-Contrast Digital Signature & Likert Scales** — Menyelaraskan kanvas tanda tangan digital (*signature pad*) dengan tinta pekat kontras dan kisi skala Likert monokromatis yang intuitif dan mudah dipilih.
- [x] **MONO-06**: **Monochrome Success & Error Feedback UX** — Memperbarui halaman sukses (`/success`) dan pesan validasi input dengan aksen terarah (badge monokrom dengan indikator aksen fungsional yang halus/restrained) agar kejelasan status pengiriman tetap terjaga.

### Admin Suite & Form Builder

- [x] **MONO-07**: **Admin Dashboard & Form Editor Monochrome Overhaul** — Memperbarui tampilan `/admin/login`, `/admin/forms`, editor form (`/admin/forms/[id]/edit`), tab navigasi langkah, kartu field accordion, outline navigation peta form, dan floating toolbar ke tema monokrom yang elegan.
- [x] **MONO-08**: **Submissions Table & Export Monochrome Alignment** — Menyelaraskan tabel data kiriman (`/admin/forms/[id]/submissions`), sticky table headers, badge filter status, dialog ekspor Excel, dan panel ringkasan AI dalam estetika monokromatis.

### Quality Assurance & Build Integrity

- [x] **MONO-09**: **Regression Testing & Production Build Verification** — Memastikan seluruh fungsionalitas (interaktivitas form, auto-save, export, worker, validasi) tetap bekerja 100%, seluruh test unit lolos (`npm run test`), lint bersih (`npm run lint`), TypeScript strict lulus (`npx tsc --noEmit`), dan Next.js production build berhasil (`npm run build`).
