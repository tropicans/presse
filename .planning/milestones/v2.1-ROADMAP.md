## Phases Summary

### Phase 37: Database Schema, Migration & Core Domain Helpers for Admin Invitations
- Created PostgreSQL enums `AdminRole` (`SUPERADMIN`, `ADMIN`) and `InvitationStatus` (`PENDING`, `ACCEPTED`, `REVOKED`, `EXPIRED`) in `prisma/schema.prisma`.
- Created models `AdminUser` (table `admin_users`) and `AdminInvitation` (table `admin_invitations`).
- Deployed migration `20260928000000_add_admin_invitations/migration.sql`.
- Built core domain logic in `src/lib/admin-invitations.ts`: token generator (64-char crypto hex), 48h expiration calculation, invitation creation, token lookup with lazy expiration, acceptance transaction, root superadmin check, and revocation protection.
- 12 unit tests in `src/lib/admin-invitations.test.ts`.

### Phase 38: NextAuth Integration & Admin User Management API Routes
- Extended NextAuth types in `src/types/next-auth.d.ts` for `session.user.role` and `session.user.isSuperAdmin`.
- Updated `signIn` callback in `src/lib/auth.ts`: dynamically checks `.env` root superadmins, active database users, and auto-claims unexpired pending invitations upon Google Sign-In.
- Enriched `session` callback with accurate role metadata.
- Implemented Superadmin management API routes:
  - `GET /api/admin/users`: Lists active team members and pending invites.
  - `POST /api/admin/users/invite`: Creates 48h invitation and returns shareable URL.
  - `POST /api/admin/users/revoke`: Revokes invites or deactivates users.
- Implemented public verify and accept routes:
  - `GET /api/public/invite/verify`: Validates token and returns public invitation info.
  - `POST /api/public/invite/accept`: Authenticated endpoint to claim invitation.
- 11 API unit tests in `src/app/api/admin/users/users-api.test.ts`.

### Phase 39: Admin Team UI & Public Invitation Claim Flow
- Built Superadmin Team Management Dashboard (`/admin/users`) via `src/app/admin/users/page.tsx` and `src/components/AdminUsersManagement.tsx`:
  - KPI summary metrics (Total Aktif, Pending, Superadmin).
  - Invite form with email, role selector, and 1-click "Salin Tautan" button.
  - Tables for active members and pending invitations with revocation confirmation modal dialogs.
- Integrated `Pengguna / Tim` sidebar navigation link across `AdminFormsList.tsx` and `AdminTable.tsx`.
- Built Public Invitation Claim page (`/admin/invite`) via `src/app/admin/invite/page.tsx` and `src/components/AdminInviteClaim.tsx`:
  - Validates token on server.
  - Renders invitation card with invited email, role, expiration countdown, and "Terima Undangan & Masuk dengan Google" button.
  - Handles auto-claim if already logged in with matching Google account.
