# Roadmap - Milestone v1.6: Form Input Validation & Submission Integrity

Milestone goal: Mengaudit, memperketat, dan menyelaraskan seluruh validasi isian form (Nama Lengkap, NIP/NRP, Nomor WhatsApp/Telepon, Email, Teks Bebas, Pilihan, dan Tanda Tangan) pada form publik dan endpoint pengiriman server-side dengan feedback pengguna yang ramah dan konsisten.

---

## Phase 17: Core Format Validators & Server-Side Enforcement

Goal: Membangun modul validasi dan sanitasi terisolasi di `src/lib/form-validation.ts` serta integrasi penegakan server-side di `validateFormSubmission` (`src/lib/forms.ts`).
Requirements: VALID-01, VALID-02, VALID-03, VALID-04, VALID-05, VALID-10

### Success Criteria

1. Modul `src/lib/form-validation.ts` menyediakan fungsi murni validasi & sanitasi untuk NIP/NRP, Email, Nomor Telepon/WA, Nama Lengkap, dan Tanda Tangan tanpa dependensi database.
2. Endpoint server `validateFormSubmission` memvalidasi dan menolak payload tidak valid dengan status HTTP 400 dan pesan bahasa Indonesia yang jelas.
3. Nilai yang disimpan ke database telah dinormalisasi (sanitized) secara otomatis.

---

## Phase 18: Client-Side Form UX & Inline Error Feedback

Goal: Menyematkan validasi format langsung di formulir publik (`AttendanceForm`) dan pratinjau admin (`AdminFormPreview`) dengan umpan balik ramah (auto-clear, focus, auto-scroll, hints, mobile inputModes).
Requirements: VALID-06, VALID-07, VALID-08, VALID-09

### Success Criteria

1. Validasi langkah mengecek aturan format saat tombol "Langkah Selanjutnya" atau "Kirim Formulir" ditekan.
2. Error validasi inline otomatis hilang (auto-clear) segera saat pengguna mengetik untuk memperbaiki isian.
3. Form otomatis fokus dan menggulirkan viewport ke field error pertama.
4. Input mode pada mobile (`numeric`, `email`, `tel`) dan teks hint format tampil tepat di bawah label.
5. AdminFormPreview memiliki kelakuan visual dan sanitasi yang selaras dengan form publik.

---

## Phase 19: Comprehensive Validation Test Suite & Regression Verification

Goal: Pengujian otomatis komprehensif untuk seluruh aturan validasi dan verifikasi penuh terhadap regresi kode.
Requirements: VALID-11

### Success Criteria

1. Seluruh validator, sanitizers, detectors, dan hint helpers teruji secara komprehensif di `src/lib/forms.test.ts`.
2. Skenario integrasi multi-field form submission pipeline teruji untuk kasus valid dan penolakan error.
3. Seluruh suite pengujian otomatis (`npm test`) lulus 100%.
4. TypeScript (`tsc --noEmit`), ESLint (`npm run lint`), dan Next.js production build (`npm run build`) berjalan bersih tanpa error.
