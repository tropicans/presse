# Roadmap - Milestone v1.9: Interactive Analytics & Submission Data Visualization

Milestone goal: Membangun antarmuka analitik interaktif yang menyajikan ringkasan KPI data respon formulir/kuis, visualisasi tren harian menggunakan grafik arsitektural, diagram distribusi jawaban per pertanyaan (pilihan, Likert, kuis), serta filter lanjutan dalam estetika Editorial Minimalist Monochrome.

---

## Phase 28: Submission Analytics Dashboard & Distribution Visualization UI

Goal: Merancang dan membangun dashboard analitik respon formulir (`/admin/forms/[id]/analytics`) dengan kartu metrik KPI, grafik bar arsitektural volume pengiriman harian, breakdown distribusi pilihan jawaban, dan suite filter reaktif.
Requirements: ANLY-01, ANLY-02, ANLY-03, ANLY-04

### Success Criteria
1. Rute `/admin/forms/[id]/analytics` terproteksi sesi admin dengan tipografi Playfair Display dan JetBrains Mono bersiku 0px.
2. Kartu metrik ringkasan KPI menampilkan Total Respon, Rata-rata Skor Kuis, Tingkat Kelulusan, Respon Terakhir, dan Jumlah Pertanyaan.
3. Visualisasi tren pengiriman harian menggunakan arsitektur bar chart monokromatik kontras tinggi tanpa border-radius.
4. Breakdown distribusi jawaban per pertanyaan menampilkan horizontal meter bar dan indikator jawaban kuis benar.
5. Filter bar interaktif menyediakan seleksi rentang waktu (7 hari, 30 hari, bulan ini, semua waktu), filter partisipan, dan pencarian teks.

---

## Phase 29: Dynamic Aggregation API & Advanced Range Filter Engine

Goal: Membangun service dan endpoint agregasi data di sisi server (`GET /api/admin/forms/[id]/analytics`) untuk memproses kalkulasi analitik secara efisien langsung dari basis data tanpa membebani browser pengguna.
Requirements: ANLY-05

### Success Criteria
1. Helper domain `getFormAnalytics(id, options)` terimplementasi di `src/lib/forms.ts`.
2. Route handler Next.js `GET /api/admin/forms/[id]/analytics` terproteksi NextAuth session dan menangani query params (`range`, `participantType`, `search`).
3. `FormAnalyticsView.tsx` terintegrasi dengan pemanggilan API backend secara reaktif dengan debounce pencarian teks.
4. Unit test kalkulasi analitik dan parameter agregasi lulus uji tanpa regresi.

---

## Phase 30: Analytics Verification, Export Integration & Docker Up

Goal: Melakukan verifikasi multi-tier (Vitest test suite, ESLint, TypeScript compilation, Next.js production build), membangun image Docker produksi, menjalankan container secara live, dan memastikan seluruh layanan berstatus healthy.
Requirements: ANLY-06

### Success Criteria
1. Test suite Vitest lulus 100% (69/69 passing tests).
2. ESLint lulus dengan 0 errors dan 0 warnings.
3. TypeScript compiler lulus dengan 0 type errors.
4. Build produksi Next.js standalone berhasil menghasilkan route `/admin/forms/[id]/analytics` dan `/api/admin/forms/[id]/analytics`.
5. Docker Compose berhasil mem-build `isian-runtime:local`, menjalankan container (`isian-app`, `isian-worker`, `isian-postgres`), dan verifikasi endpoint `/api/health` mengembalikan status OK.
